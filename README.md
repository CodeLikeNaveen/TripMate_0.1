# Install uv:
- open powershell and run the command
- powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# Run
- ```uv init```
    - start a basic setup
- ```uv venv```
    - creates a virtual environment
- ```.venv\Scripts\activate```
    - run to activate

# add libraries
- ```uv add -r requirements.txt```
